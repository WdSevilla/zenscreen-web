ZenScreen

Kiosk multimedia para tabletas Android — PDFs, imágenes y videos en bucle continuo, con servidor WiFi integrado, panel admin oculto y arranque automático.

Introducción

ZenScreen convierte cualquier tableta Android (8.0+) en un kiosk multimedia profesional. Pensado para recepciones, salas de espera, stands en ferias y exhibiciones donde se necesita mostrar contenido de forma continua y desatendida.

La app no requiere root. El modo kiosk se logra a través del sistema de launcher de Android, bloqueando el botón Atrás por accesibilidad y ocultando las barras del sistema.

El acceso al panel de administración se realiza mediante un toque largo en la esquina superior derecha — invisible para visitantes.

Características

  • Slideshow continuo: PDFs, imágenes y videos en bucle infinito sin intervención del usuario.
  • Servidor WiFi integrado: Sube y gestiona archivos desde cualquier browser en la misma red local.
  • Modo kiosk: Bloquea el botón Atrás, oculta barras del sistema, actúa como launcher.
  • Orden configurable: Arrastra para reordenar el playlist desde la app o desde el dashboard WiFi.
  • Panel admin oculto: Acceso mediante PIN con toque largo en esquina superior derecha.
  • Arranque automático: Se inicia solo al encender la tablet, sin intervención manual.
  • Orientación configurable: Retrato, paisaje o automático según necesidad.
  • Sin root: No requiere permisos de superusuario.

Requisitos

  • Android 8.0 (API 26) o superior
  • Red WiFi local (para el servidor de archivos)
  • Tableta recomendada: al menos 2 GB RAM, almacenamiento interno o microSD disponible
  • Para compilar: Android Studio Hedgehog o superior, JDK 17+

Instalación

A: APK directo (recomendado)

  1. Descarga el APK desde la página de releases en GitHub.
  2. En la tablet, activa Ajustes → Seguridad → Instalar apps desconocidas y habilita tu browser o gestor de archivos.
  3. Abre el APK descargado y confirma la instalación.
  4. Pulsa el botón Home para que Android pregunte qué launcher usar — selecciona ZenScreen y elige Siempre.

B: Compilar desde el código fuente

git clone https://github.com/WdSevilla/zenscreen.git
cd zenscreen
./gradlew assembleRelease

El APK generado estará en app/build/outputs/apk/release/app-release.apk. Instálalo con adb install o cópialo a la tablet.

adb install app/build/outputs/apk/release/app-release.apk

Configuración inicial

  1. Establece ZenScreen como launcher: Al pulsar Home por primera vez, Android pregunta qué app usar. Selecciona ZenScreen y elige Siempre. También puedes configurarlo en Ajustes → Apps → App por defecto → Launcher.
  2. Concede permisos: La app solicitará acceso a almacenamiento para leer archivos, y permiso de arrancar al inicio. Acepta ambos.
  3. Establece el PIN de admin: En la primera apertura del panel admin (toque largo en esquina superior derecha), se te pedirá crear un PIN de 4 dígitos. Guárdalo en un lugar seguro.

Si olvidas el PIN, tendrás que desinstalar y reinstalar la aplicación. No hay mecanismo de recuperación para proteger el modo kiosk.

Subir archivos

Vía WiFi (recomendado)

  1. Asegúrate de que la tablet y tu PC están conectados a la misma red WiFi.
  2. Abre el panel admin (toque largo, esquina superior derecha → PIN).
  3. Activa el servidor WiFi. La app mostrará una URL como http://192.168.1.xx:8080.
  4. Abre esa URL en el browser de tu PC.
  5. Arrastra archivos al área de drop o usa el botón de selección. La subida es inmediata.

Vía USB / transferencia directa

También puedes copiar archivos directamente a la carpeta interna de ZenScreen usando un cable USB y un gestor de archivos. La ruta por defecto es:

/sdcard/ZenScreen/media/

Los archivos copiados se detectan automáticamente al reiniciar el slideshow o al entrar al panel admin.

Navegación táctil

Durante el slideshow, el usuario puede navegar manualmente tocando la pantalla:

Zona de toqueAcción
Mitad izquierda← Diapositiva anterior
Mitad derecha→ Diapositiva siguiente
Esquina superior derecha (toque largo)Abre el panel admin

Los toques de navegación son completamente transparentes para el público. Solo el toque largo en la esquina activa el panel oculto.

Panel admin

Cómo abrirlo

  1. Mantén pulsada la esquina superior derecha de la pantalla durante ~1.5 segundos.
  2. Aparece un diálogo de PIN. Introduce el PIN de 4 dígitos.
  3. El panel se despliega con todas las opciones disponibles.

Gestión de archivos

Desde el panel admin puedes ver todos los archivos cargados, reordenarlos arrastrando, y eliminar los que ya no necesites. Los cambios se aplican inmediatamente al slideshow activo.

WiFi Dashboard

Cuando el servidor WiFi está activo, abre http://[IP-de-la-tablet]:8080 en cualquier browser de tu red local. El dashboard ofrece:

FunciónDescripción
Subir archivosDrag and drop o selección múltiple, progreso en tiempo real
Ver playlistLista de archivos cargados con nombre, tamaño y tipo
ReordenarDrag-and-drop en el browser para cambiar el orden
EliminarBotón de papelera por archivo con confirmación
DescargarDescarga individual de archivos al PC
PrevisualizarVista previa de imágenes y primera página de PDFs

El servidor solo es accesible desde la red local (LAN). No expone ningún puerto a Internet.

Modo kiosk

ZenScreen implementa el modo kiosk mediante una combinación de técnicas que no requieren root:

TécnicaEfecto
Launcher por defectoZenScreen se lanza al pulsar Home
Servicio de accesibilidadIntercepta y anula el botón Atrás
Immersive modeOculta barra de estado y navegación
BOOT_COMPLETED receiverArranque automático al encender la tablet
FLAG_KEEP_SCREEN_ONEvita que la pantalla se apague

Para salir del modo kiosk sin el PIN, tendrás que usar ADB: adb shell am start -n com.android.settings/.Settings

Arquitectura

Estructura de archivos

zenscreen/ ├── app/src/main/ │ ├── java/com/zenscreen/ │ │ ├── MainActivity.kt # Launcher principal, slideshow │ │ ├── AdminActivity.kt # Panel admin con PIN │ │ ├── WifiServerService.kt # Servidor HTTP (NanoHTTPD) │ │ ├── BootReceiver.kt # Arranque automático │ │ ├── KioskAccessibility.kt # Bloqueo botón Atrás │ │ ├── MediaManager.kt # Gestión del playlist │ │ └── PdfRenderer.kt # Renderizado de PDFs │ ├── res/ │ │ ├── layout/ # XML layouts │ │ └── raw/ # Assets del servidor web │ └── AndroidManifest.xml ├── build.gradle.kts └── README.md

Flujo de arranque

BOOT_COMPLETED
    └─→ BootReceiver
           └─→ MainActivity (launcher)
                  ├─→ MediaManager.loadPlaylist()
                  ├─→ SlideshowEngine.start()
                  └─→ WifiServerService.start() [si estaba activo]

API WiFi

El servidor HTTP expone una API REST simple. Todos los endpoints responden con JSON.

MétodoEndpointDescripción
GET/api/filesLista de todos los archivos en el playlist
POST/api/uploadSube uno o más archivos (multipart/form-data)
DELETE/api/files/:nameElimina un archivo por nombre
POST/api/reorderReordena el playlist (body: array de nombres)
GET/api/statusEstado del servidor y configuración actual
GET/Dashboard HTML

Solución de problemas

La app no arranca al encender

Verifica que el permiso Iniciar al arrancar esté concedido en Ajustes → Apps → ZenScreen → Permisos. En algunos fabricantes (Xiaomi, Huawei) hay un ajuste adicional de "autoarranque" en la configuración de batería.

El botón Atrás no está bloqueado

El servicio de accesibilidad debe estar activo. Ve a Ajustes → Accesibilidad → ZenScreen Kiosk y actívalo.

No aparece la IP del servidor WiFi

Asegúrate de que la tablet está conectada a una red WiFi (no solo a datos móviles). El servidor solo funciona en red local. Si cambias de red, reinicia el servidor desde el panel admin.

Los PDFs no se muestran correctamente

ZenScreen usa el PdfRenderer nativo de Android, que requiere PDFs con fuentes embebidas. PDFs generados con libreoffice o Adobe Acrobat suelen funcionar bien. PDFs escaneados sin OCR pueden mostrarse en blanco.

Los videos se traban o no reproducen

Verifica que el codec del video sea compatible con el hardware de la tablet. MP4 con H.264 tiene la mayor compatibilidad. Para MKV con H.265, la tablet necesita soporte de decodificación hardware.

Olvidé el PIN de admin

Desinstala y reinstala la aplicación. Los archivos subidos se conservan en /sdcard/ZenScreen/media/ y estarán disponibles al volver a instalar.

No puedo instalar el APK

Activa Fuentes desconocidas en Ajustes → Seguridad. En Android 8+, debes habilitarlo específicamente para el app desde la que vas a instalar (browser, gestor de archivos).
